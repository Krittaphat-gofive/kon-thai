ต่างกันที่ stash เป็นที่พักชั่วคราวนอก history ส่วน commit อยู่ใน history จริงครับ

- **stash** เก็บงานค้างไว้ในกองซ้อนกลางทาง ไม่ผูกกับ branch ไหน ไม่มี commit message ให้ค้นทีหลัง และ push ขึ้น remote ไม่ได้ ถ้าลืมไว้นาน ๆ จะจำไม่ได้ว่าอันไหนคืออะไร
- **commit** มี hash มี message มีคนเขียนกำกับ อยู่บน branch ชัดเจน push สำรองขึ้น remote ได้ ถ้ายังไม่อยากให้เข้า history สุดท้าย ก็ `--amend` หรือ squash ทีหลังได้

ใช้แบบนี้
- สลับ branch แป๊บเดียวแล้วกลับมาทำต่อ: stash
- งานค้างข้ามวัน หรืออยากสำรองกันเครื่องพัง: commit ไว้บน branch ตัวเอง (เขียน message ว่า `wip: ...`) แล้วค่อยจัดระเบียบตอนจะ merge

ถ้าอยากได้ท่า cleanup commit `wip` ก่อนเปิด PR เดี๋ยวเขียนให้ได้ครับ
