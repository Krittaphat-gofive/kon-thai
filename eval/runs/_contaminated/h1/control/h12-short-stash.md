ต่างกันที่ "เก็บไว้ไหน" กับ "ตามรอยได้แค่ไหน" ครับ

**git stash**
- เก็บงานค้างไว้ใน stack แยกต่างหาก ไม่อยู่ใน history ของ branch
- ไม่ผูกกับ branch ไหน เอาไป pop ที่ branch อื่นได้
- push ขึ้น remote ไม่ได้ ถ้าเครื่องพังก็หายไปด้วย
- ลืมง่าย เพราะมองไม่เห็นใน log ปกติ

**WIP commit**
- เข้า history ของ branch จริง ๆ มี hash อ้างอิงได้
- push ขึ้น remote ได้ เป็น backup ไปในตัว
- ย้อนกลับมาแก้ด้วย `git commit --amend` หรือ `git rebase -i` ทีหลังได้

เลือกแบบนี้
- สลับ branch แป๊บเดียวแล้วกลับมาทำต่อ: `git stash`
- งานค้างข้ามวัน หรืออยากให้มี backup บน remote: commit ไว้เลย แล้วค่อย squash ตอนจะเปิด PR

ส่วนตัวผมเชียร์ WIP commit มากกว่าเกือบทุกเคส เพราะ stash ที่ดองไว้หลายอันนี่หา pop ถูกตัวยากมาก ถ้าอยากได้ flow การ squash ตอนจบ เดี๋ยวเขียนให้ดูได้ครับ
