ต่างกันที่ว่างานนั้นเข้าไปอยู่ใน history หรือเปล่าครับ

- **commit** บันทึกลง history ของ branch มีตัวตนถาวร push ขึ้น remote ได้ กู้คืนง่ายแม้ผ่านไปเป็นเดือน
- **stash** เก็บงานค้างไว้นอก history เป็น stack กลาง ๆ ของ repo ไม่ผูกกับ branch ไหน push ไม่ได้ และถ้าเผลอ `stash drop` หรือ `stash clear` ไปแล้วตามคืนยากกว่ามาก

เลือกแบบนี้
- สลับ branch ไปแก้งานด่วนแป๊บเดียว แล้วจะกลับมาทำต่อ: `git stash`
- งานค้างข้ามวัน หรืออยากให้มีร่องรอยไว้: commit ไปก่อนเลย ใช้ WIP commit แล้วค่อย `git commit --amend` หรือ rebase รวบทีหลังตอนจะเปิด PR

ส่วนตัวถ้าค้างเกินครึ่งวันผมเลือก commit ครับ เพราะ stash ที่ดองไว้หลายอันสุดท้ายจะจำไม่ได้ว่าอันไหนคืออะไร
