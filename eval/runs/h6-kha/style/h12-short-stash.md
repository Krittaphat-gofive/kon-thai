ต่างกันที่ของไปอยู่ไหนค่ะ stash เก็บไว้นอก branch เป็นกองแยก ส่วน commit เก็บเข้า history ของ branch นั้นเลย

- **stash**: ไม่ผูกกับ branch เลยเอาไปใช้ข้าม branch ได้ง่าย `git stash pop` แล้วงานกลับมาเป็น working directory เหมือนเดิม เหมาะกับงานค้างสั้น ๆ ตอนจะสลับไปแก้อย่างอื่น
- **commit เก็บไว้ก่อน**: ได้ hash มีตัวตนจริงใน branch push ขึ้น remote ได้ ไม่หายแม้เครื่องพัง เวลาจะเอาออกต้อง `git reset --soft HEAD~1` หรือ amend ทีหลัง

ที่คนนิยม commit มากกว่าเพราะ stash ค้างหลายอันแล้วลืมว่าอันไหนคืออะไร (`stash@{3}` ไม่บอกอะไรเลย) ส่วน commit ตั้งชื่อ message ได้ เช่น `wip: ค้างไว้ตรง validate form` แล้วค่อย squash ตอนจะ merge

สรุปง่าย ๆ ค้างไม่เกินวันสองวันและไม่อยากให้มีร่องรอยใน log ใช้ stash นอกนั้น commit ปลอดภัยกว่า
