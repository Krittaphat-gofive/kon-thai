1. **Race condition** — ถ้า validate โควตาแล้วค่อย insert โดยไม่มี lock หรือ transaction พนักงานยิงคำขอพร้อมกันสองใบอาจผ่านทั้งคู่ได้ คุ้มที่จะเช็กว่าโค้ดจริงจัดการตรงนี้ไว้หรือยัง
