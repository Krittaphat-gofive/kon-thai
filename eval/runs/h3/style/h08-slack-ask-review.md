**ข้อความหลัก**

> รบกวนฝาก review PR นี้หน่อยครับ 🙏 [ลิงก์]
>
> ไฟล์เยอะหน่อยนะ ~40 ไฟล์ แต่ประมาณ 30 ไฟล์เป็น rename กับย้าย import ไล่ผ่าน ๆ ได้เลย
>
> จุดที่อยากให้ช่วยดูจริง ๆ มี 3 ที่
> • `ไฟล์ A` : logic หลักของ feature นี้
> • `ไฟล์ B` : เปลี่ยนวิธี handle error ตรงนี้อยากได้ความเห็นมากสุด
> • `ไฟล์ C` : migration ช่วยดูว่า rollback ได้จริงไหม
>
> ไม่ต้องรีบครับ ได้ภายใน [วัน] ก็สบายมากแล้ว ใครมีเวลาดูได้แค่บางไฟล์ก็ comment ไว้ได้เลย ไม่ต้องรอดูครบค่อยส่ง
>
> ถ้าอ่านแล้วงงตรงไหน ทักมาได้เลย หรือจะนัด 15 นาทีให้เล่าภาพรวมให้ฟังก่อนก็ได้ครับ

> ฝาก review PR นี้หน่อยครับ [ลิงก์] 🙏

**ที่ใส่ไว้แต่ละจุดเพราะ**
- บอกจำนวนไฟล์เองตั้งแต่แรก ดีกว่าให้เขาไปเปิดเจอเองแล้วใจแป้ว
- แยกให้เห็นว่าไฟล์เยอะกับงานเยอะไม่เท่ากัน ตรงนี้ลดแรงกดดันได้มากที่สุด
- บอกว่า review แค่บางส่วนก็รับ ทำให้คนที่มีเวลาน้อยกล้าเริ่ม
- เสนอเล่าภาพรวมให้ฟัง ย้ายภาระการทำความเข้าใจกลับมาที่เราเอง
