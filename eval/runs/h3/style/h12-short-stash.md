ต่างกันที่ของไปอยู่ไหนครับ stash เก็บไว้นอก history ไม่ผูกกับ branch ส่วน commit เข้าไปอยู่ใน history ของ branch นั้นเลย

ผลที่ตามมา
- stash: ไม่ต้องตั้งชื่อ ไม่เลอะ log แต่ push ขึ้น remote ไม่ได้ ถ้าลืมไว้นาน ๆ หรือ stash ซ้อนกันหลายอัน มักจำไม่ได้ว่าอันไหนคืออะไร แล้วตอน pop ก็มีโอกาสชน conflict
- commit WIP: ของอยู่ครบ push กันเครื่องพังได้ ย้อนดูง่าย แต่ต้องตามเก็บทีหลัง เช่น `git commit --amend` หรือ `git reset --soft HEAD~1` ก่อนเปิด PR

เลือกแบบนี้
- สลับ branch ไปแก้ bug ด่วนแป๊บเดียว เดี๋ยวกลับมาต่อ: stash
- งานค้างข้ามวัน หรืออยากกันของหาย: commit WIP ไว้ก่อน
