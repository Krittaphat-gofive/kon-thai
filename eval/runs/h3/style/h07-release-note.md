# Release Note เวอร์ชัน [x.y.z]

**วันที่อัปเดตระบบ:** [วันที่]

รอบนี้มี 2 เรื่อง คือเพิ่มการอนุมัติใบลาแบบหลายขั้น และแก้รายงานภาษีหัก ณ ที่จ่ายที่แสดงข้อมูลผิดเดือน

## ฟีเจอร์ใหม่: อนุมัติใบลาได้หลายขั้น

เดิมใบลาผ่านผู้อนุมัติคนเดียวแล้วจบ ตอนนี้กำหนดได้ว่าใบลาต้องผ่านใครบ้างตามลำดับ เช่น หัวหน้างาน → ผู้จัดการฝ่าย → HR

สิ่งที่ทำได้

- ตั้งขั้นการอนุมัติได้สูงสุด [n] ขั้น แยกเงื่อนไขตามประเภทการลา หน่วยงาน หรือจำนวนวันที่ลา
- ใบลาจะเดินไปขั้นถัดไปเมื่อขั้นก่อนหน้าอนุมัติแล้วเท่านั้น ถ้าขั้นไหนไม่อนุมัติ ใบลาจะปิดทันทีและแจ้งกลับไปที่พนักงานพร้อมเหตุผล
- ผู้อนุมัติแต่ละขั้นได้รับแจ้งเตือนทาง [อีเมล / แอปมือถือ] เมื่อถึงคิวตัวเอง
- หน้าติดตามสถานะใบลาแสดงให้เห็นว่าตอนนี้ค้างอยู่ขั้นไหน ใครอนุมัติไปแล้วบ้าง และอนุมัติเมื่อไหร่
- ตั้งผู้อนุมัติสำรองได้ กันกรณีผู้อนุมัติหลักลาหรือไม่อยู่

สิ่งที่ต้องทำก่อนเริ่มใช้

- ผู้ดูแลระบบฝั่ง HR ตั้งค่าสายอนุมัติที่เมนู [ตั้งค่า > การอนุมัติใบลา]
- ใบลาที่ยื่นค้างไว้ก่อนอัปเดต ยังใช้สายอนุมัติเดิมจนกว่าจะปิดใบ พนักงานไม่ต้องยื่นใหม่
- ถ้ายังไม่ตั้งค่าอะไรเลย ระบบใช้การอนุมัติขั้นเดียวแบบเดิม การใช้งานปัจจุบันไม่สะดุด

## แก้ไข: รายงานภาษีหัก ณ ที่จ่าย แสดงผิดเดือน

**อาการ:** รายงานภาษีหัก ณ ที่จ่าย จัดบางรายการไปอยู่ผิดเดือน ทำให้ยอดรวมรายเดือนคลาดเคลื่อน

**สาเหตุ:** [ระบบยึดวันที่ทำรายการจ่ายแทนงวดเงินเดือน รายการที่จ่ายคาบเกี่ยวสิ้นเดือนเลยไปตกอยู่เดือนถัดไป]

**ขอบเขตที่กระทบ:** รายงานงวด [เดือน/ปี ถึง เดือน/ปี]

**เรื่องที่อยากให้สบายใจ:** ยอดภาษีที่หักจากพนักงานและที่นำส่งกรมสรรพากรถูกต้องตามเดิม ปัญหาอยู่ที่การจัดกลุ่มเดือนในรายงานอย่างเดียว ไม่กระทบยอดเงินในสลิปหรือยอดสะสมรายปี

**สิ่งที่ต้องทำ:**

- ดึงรายงานของงวดที่กระทบใหม่อีกครั้ง ตัวเลขจะตรงทันที ไม่ต้องแก้ข้อมูลย้อนหลังเอง
- ถ้านำส่งเอกสารงวดที่กระทบไปแล้ว แนะนำให้เทียบยอดกับรายงานฉบับใหม่ก่อน หากพบส่วนต่าง ติดต่อทีมงานที่ [ช่องทางติดต่อ] จะช่วยตรวจสอบและแนะนำขั้นตอนยื่นเพิ่มเติมให้
