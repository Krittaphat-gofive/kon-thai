# Release Note เวอร์ชัน [x.y.z]

วันที่ปล่อยระบบ [วัน เดือน ปี]

รอบนี้มีของใหม่ 1 รายการ และแก้ข้อบกพร่อง 1 รายการ

## ฟีเจอร์ใหม่

### กำหนดผู้อนุมัติใบลาได้หลายขั้น

เดิมใบลา 1 ใบผ่านผู้อนุมัติได้ชั้นเดียว ตอนนี้ตั้งลำดับผู้อนุมัติได้หลายขั้น เช่น หัวหน้างาน ผู้จัดการฝ่าย แล้วค่อยถึง HR

วิธีทำงาน
- ใบลาจะส่งไปหาผู้อนุมัติขั้นที่ 1 ก่อน เมื่ออนุมัติแล้วระบบจึงส่งต่อไปขั้นถัดไปอัตโนมัติ
- ถ้าขั้นใดขั้นหนึ่งไม่อนุมัติ ใบลาจะจบที่ขั้นนั้น และแจ้งกลับไปที่พนักงานผู้ยื่น
- พนักงานดูได้ว่าใบลาค้างอยู่ที่ขั้นไหน ใครเป็นผู้อนุมัติ

สิ่งที่ HR ต้องทำ
- ตั้งค่าลำดับผู้อนุมัติที่เมนู [ชื่อเมนู] ก่อนเริ่มใช้งาน
- ใบลาที่ยื่นไว้ก่อนอัปเดต [ระบุว่ายังใช้ flow เดิมจนจบ หรือเข้าสู่ flow ใหม่]

## แก้ไขข้อบกพร่อง

### รายงานภาษีหัก ณ ที่จ่ายแสดงข้อมูลผิดเดือน

อาการเดิม: เลือกเดือนที่ต้องการแล้ว แต่รายงานแสดงข้อมูลของอีกเดือนหนึ่ง

แก้ไขแล้ว ตอนนี้รายงานดึงข้อมูลตรงตามเดือนที่เลือก

สิ่งที่ HR ควรตรวจสอบ
- ถ้าเคยออกรายงานช่วง [ช่วงเวลาที่ได้รับผลกระทบ] และนำไปใช้ยื่นหรือส่งต่อแล้ว แนะนำให้ออกรายงานใหม่เพื่อเทียบตัวเลขอีกครั้ง
- ข้อมูลเงินเดือนและภาษีในระบบไม่ได้รับผลกระทบ ปัญหาอยู่ที่การแสดงผลในรายงานเท่านั้น [ยืนยันข้อนี้กับทีม dev ก่อนส่งออก]

หากพบปัญหาการใช้งาน ติดต่อทีมงานได้ที่ [ช่องทางติดต่อ]

จุดที่อยากให้เช็กก่อนส่งให้ลูกค้า
- ใบลาที่ค้างอยู่ตอน deploy จะวิ่งตาม flow เดิมหรือ flow ใหม่ ข้อนี้ HR ถามแน่
- ช่วงเวลาที่รายงานภาษีแสดงผิด เพราะลูกค้าต้องเอาไปไล่ว่าต้องออกรายงานใหม่กี่เดือน
- บั๊กนี้กระทบแค่การแสดงผล หรือกระทบข้อมูลที่เก็บด้วย ถ้ากระทบข้อมูลจริงต้องเขียนใหม่ให้หนักกว่านี้ครับ
