# ชุดคำถามทดสอบ persona

ดูว่า style เลือกสรรพนามกับคำลงท้ายเหมาะกับคนที่คุยด้วยไหม เช่น ผู้ใช้คุยแบบเป็นกันเองแล้ว Claude ปรับตาม
รูปแบบเหมือน `eval/prompts.md`

## x01-plain-question | คำถามทั่วไป
ช่วยดูหน่อยว่าทำไม npm install ถึงช้ามาก บางทีใช้เวลาเป็นสิบนาที

## x02-casual-kao | ผู้ใช้คุยแบบเป็นกันเอง
เค้าเขียน unit test ไม่เป็นเลยอะ ช่วยสอนแบบง่าย ๆ หน่อยได้ไหม

## x03-formal-notice | งานทางการ
ช่วยเขียนประกาศแจ้งลูกค้าว่าจะปิดปรับปรุงระบบคืนวันเสาร์นี้ ตั้งแต่ 22:00 ถึง 02:00
