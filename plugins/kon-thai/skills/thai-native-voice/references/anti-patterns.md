# แคตตาล็อกภาษาแปล

ร่องรอยที่ทำให้ภาษาไทยฟังเหมือนแปลมาจากภาษาอังกฤษ พร้อมวิธีแก้และที่มา
ตัวอย่างที่ติดป้าย "baseline" มาจากคำตอบจริงของ Claude ตอนยังไม่มี style

## สารบัญ

1. โครงสร้างประโยค
2. คำเชื่อมและวลีสำเร็จรูป
3. สำนวนอังกฤษแปลตรงตัว และแพตเทิร์นระดับคำตอบ
4. สรรพนามและคำลงท้าย
5. อย่าแก้เกินเหตุ
6. ที่มา

## 1. โครงสร้างประโยค

### ถูก + กริยา กับเรื่องปกติ

ภาษาไทยใช้ "ถูก" กับเรื่องที่ไม่ดีต่อผู้ถูกกระทำ ถ้าเป็นเรื่องปกติ ให้บอกว่าใครทำ หรือเขียนโดยไม่ต้องมีประธาน [ราชบัณฑิตฯ 2547] [จุฬาฯ] [Microsoft]

| ภาษาแปล | แบบคนไทย |
|---|---|
| การประชุมถูกจัดขึ้นอย่างเร่งรีบ | การประชุมจัดขึ้นอย่างเร่งรีบ [จุฬาฯ] |
| This program couldn't be downloaded | ไม่สามารถดาวน์โหลดโปรแกรมนี้ได้ [Microsoft] |
| parent ก็ถูกเช็คไปแล้ว (baseline) | Angular เช็ก parent ไปแล้ว |
| context ตัวเดียวถูกใช้ร่วมกันทุก request (baseline) | ทุก request เลยใช้ context ตัวเดียวกัน |
| ประวัติเดิมไม่ถูกแตะ (baseline) | ไม่แตะประวัติเดิม |

ใช้ "ถูก" ได้ตามปกติเมื่อเป็นเรื่องไม่ดี เช่น ถูกแฮ็ก ถูกปฏิเสธ ถูกบล็อก คนไทยเองก็ใช้ "ถูก" กับเรื่องกลาง ๆ อยู่บ้าง เช่น "Credentials จะถูกเก็บไว้ที่ ~/.local/share/opencode/auth.json" (บล็อก devahoy) เป้าหมายจึงเป็นการลดความถี่ ไม่ใช่ลบทุกคำ ข่าว Blognone ใช้ราว 0.43 ครั้งต่อ 1,000 ตัวอักษร ส่วนคำตอบของ Claude ตอนยังไม่มี style ใช้ 1.09 [calibrate]

ลำดับการแก้: เขียนแบบไม่มีประธานก่อน ("ยังไม่ได้เก็บข้อมูลจริง", "component นี้ destroy ไปแล้ว") ยกผู้กระทำขึ้นมาเป็นประธานเฉพาะตอนที่บริบทบอกชัดว่าใครทำ เช่น ตอน rebase คือ git อย่าเดาผู้กระทำขึ้นมาเองเพื่อให้ประโยคเป็น active [Codex]

กับดัก: อย่าแก้ "ถูก" เป็น "ได้รับ" ทุกที่ งานวิจัยคลังข้อความงานแปลกฎหมายพบว่าภาษาไทยที่แปลจากอังกฤษใช้ "ได้รับ" 5,711 ครั้งต่อล้านคำ ส่วนภาษาไทยที่เขียนเองใช้ 3,164 ครั้ง [Satthachai 2019] "ได้รับการ + กริยา" ยังทำให้กริยากลายเป็นคำนามอีกด้วย

### มันเป็น… / มันคือ… แบบ It is…

[ราชบัณฑิตฯ 2547] [จุฬาฯ] [ครูภาษาไทย]

| ภาษาแปล | แบบคนไทย |
|---|---|
| มันเป็นอะไรที่ยากแก่การคาดเดา | เรื่องนี้คาดเดายาก [ครูภาษาไทย] |
| มันเป็นการยากที่จะปฏิบัติตาม… | …ปฏิบัติตามยาก [ครูภาษาไทย] |
| มันเป็นที่ชัดเจนว่า | เห็นได้ชัดว่า [kien-thai] |

### มัน แทน it

Microsoft แนะนำให้เลี่ยง "มัน" ในงานเขียนที่ไม่ใช่นิยาย [Microsoft] แต่ dev ไทยใช้ "มัน" แทนโค้ดหรือเครื่องมือที่เพิ่งพูดถึงกันเป็นปกติ เช่น "ถ้ามันแจ้ง error ว่าหาไฟล์ไม่เจอ ก็ค่อยให้ระบุค่าลงไป" (README ของ jquery.Thailand.js) คอมเมนต์ใน Blognone ใช้ราว 4.9 ครั้งต่อ 1,000 ตัวอักษร ข่าว Blognone ใช้ 0.17 ส่วน Claude ตอนยังไม่มี style ใช้ 0.74 [thai-online-writing] [calibrate]

สรุปคือ "มันเป็น…" / "มันคือ…" ยังเป็นภาษาแปล (หัวข้อก่อนหน้า) ส่วน "มัน" ที่หมายถึงสิ่งที่เพิ่งพูดถึงใช้ได้ ให้แก้เฉพาะตอนที่ใช้ถี่จนอ่านแล้วไม่ชัดว่าหมายถึงอะไร คำว่า "ตัวนี้" กับ "แบบนี้" ก็กำกวมได้เหมือนกันถ้าใช้ถี่ [Codex]

| ภาษาแปล | แบบคนไทย |
|---|---|
| หรือให้มันลอยอยู่ | หรือให้ลอยอยู่ [Microsoft] |
| ข้างในมันมี change tracker (baseline) | ข้างใน DbContext มี change tracker |
| มันทำให้ query เป็น non-SARGable (baseline) | เงื่อนไขแบบนี้ทำให้ query เป็น non-SARGable |

## 2. คำเชื่อมและวลีสำเร็จรูป

- ซึ่ง / โดย / ดังนั้น ใช้ไม่เกินคำละครั้งต่อย่อหน้า [kien-thai]
- อย่างไรก็ตาม → แต่ [Microsoft]
- นอกจากนี้ → แล้วก็… / อีกเรื่องคือ… หรือขึ้นย่อหน้าใหม่ [kien-thai]
- ประสบ → พบ, เจอ / ค้นหา → หา / ให้ความช่วยเหลือ → ช่วย / อ้างอิงไปที่ → ดู [Microsoft]
- ในอนาคตอันใกล้นี้ → เร็ว ๆ นี้ / นำมาซึ่ง, ก่อให้เกิด → ทำให้เกิด / เต็มไปด้วย → มี…เยอะ / ในกรณีของ… → ถ้า… [ครูภาษาไทย]
- เพื่อที่จะ → เพื่อ หรือ จะได้
- ดำเนินการแก้ไข → แก้ / หาก → ถ้า / ส่งผลให้ → ทำให้ (ในแชตและเอกสารกึ่งทางการ)

## 3. สำนวนอังกฤษแปลตรงตัว (baseline)

ดูก่อนว่าสำนวนนั้นหมายความว่าอะไรในบริบท แล้วเขียนความหมายนั้นแบบที่คนไทยพูด ถ้าไม่มีสำนวนไทยที่ตรงกัน ให้พูดตรง ๆ หรือคงคำอังกฤษไว้ อย่าจับคู่คำแทนแบบตายตัว เพราะน้ำหนักความหมายมักไม่เท่ากัน เช่น "กฎเหล็ก" แรงกว่า "golden rule" และ "ช่วยได้มากที่สุด" เติมการเปรียบเทียบที่ต้นฉบับไม่มี [Codex]

| ภาษาแปล | ต้นทาง | ตัวอย่างที่เขียนตามบริบท |
|---|---|---|
| กฎทองข้อเดียว: อย่า rebase branch ที่แชร์กัน | golden rule | กฎข้อเดียวที่ห้ามพลาด |
| เป็นยาแก้ปวด | band-aid | แก้ที่ปลายเหตุ, แก้ขัด |
| โรย setTimeout ทุกที่ | sprinkle | ใส่ setTimeout ไปทั่ว |
| ตารางนี้คือตัวเปลี่ยนเกม | game changer | บอกว่าตารางช่วยอะไร เช่น ทำให้ PM เห็นว่าเวลาไปหมดที่ไหน |
| ปัญหาคลาสนี้ | this class of problems | ปัญหาแบบนี้ |
| ตัวแปรที่อาจเปลี่ยนคำตอบ | variables | กรณีที่คำตอบจะต่างไป |
| ลูกผสม | hybrid | ใช้ผสมกัน |
| เรามาเจาะลึกกัน | let's dive deep | เข้าเรื่องเลย |

## 3.1 แพตเทิร์นระดับคำตอบ

เรื่องพวกนี้แต่ละประโยคอาจถูกภาษาแล้ว แต่พออ่านทั้งคำตอบจะรู้สึกว่าเป็นแม่แบบ [Codex]

| ภาษาแปล | แบบคนไทย |
|---|---|
| ตรวจสอบให้แน่ใจว่าคุณได้ปิด connection (ensure that) | อย่าลืมปิด connection หลังใช้งาน |
| ในแง่ของประสิทธิภาพ query นี้… (in terms of) | query นี้ช้าตรงที่… |
| สิ่งนี้ช่วยแก้ปัญหาดังกล่าว | unique constraint ช่วยกันข้อมูลซ้ำ (เรียกชื่อสิ่งนั้น) |
| แนวทางนี้มีความยืดหยุ่นและมีประสิทธิภาพสูง | บอกผลจริงที่รู้ เช่น เพิ่มเงื่อนไขได้ง่าย ยิง query น้อยลง |
| โดยสรุป วิธีนี้ช่วยให้โค้ดมีคุณภาพดีขึ้น | ตัดทิ้ง หรือบอกผลที่เจาะจงกว่า |
| เป็นคำถามที่ดีมาก เรามาเจาะลึกกัน | เข้าเรื่องเลย |

- ปิดท้ายด้วยการเสนอช่วยต่อทุกคำตอบ อ่านแล้วเหมือนแม่แบบ style v1 ปิดแบบนี้ 19 จาก 20 คำตอบ ส่วนคอมเมนต์ของ dev ไทยตอบจบแล้วก็หยุดเลย ให้ถามกลับเฉพาะตอนที่ต้องการข้อมูลจากผู้ใช้จริง ๆ [thai-online-writing]
- ทุกหัวข้อยาวเท่ากัน ทุกข้อมีคำอธิบายครบสูตร ให้แต่ละส่วนยาวตามเนื้อหาจริง

## 4. สรรพนามและคำลงท้าย

- ผู้ชายไทยแทบไม่ใช้ "ฉัน" เวลาคุยกัน และภาษาไทยไม่มีสรรพนามแทนตัวเองที่ใช้ได้กับทุกคน [Microsoft] ชุดนี้มี persona ให้เลือกสองแบบ คือ ผม/ครับ กับ ดิฉัน/ค่ะ และละสรรพนามเมื่อทำได้
- persona ดิฉัน/ค่ะ: ประโยคบอกเล่าลงท้าย "ค่ะ" ประโยคคำถามลงท้าย "คะ" และเขียน "นะคะ" ไม่ใช่ "นะค่ะ" ข้อนี้เป็นจุดที่เขียนผิดกันบ่อยที่สุด
- "คุณ" ละได้เกือบทุกครั้ง [Microsoft]
- ไม่ต้องลงท้ายด้วยคำลงท้ายทุกประโยค แม้แต่บทสนทนาแม่กับลูกก็ไม่ต้องลงท้ายด้วย "จ๊ะ" ตลอด [ราชบัณฑิตฯ 2547]
- เนื้อความในเอกสาร เช่น README หรือคู่มือ ไม่มีคำลงท้าย ใส่ได้เฉพาะคำทักทายหรือคำปิดท้าย [kien-thai]

## 5. อย่าแก้เกินเหตุ

- "ไม่สามารถ…ได้" เป็นรูปมาตรฐานของ error message ใน UI [Microsoft] ข่าว Blognone ใช้ "สามารถ" 1.28 ครั้งต่อ 1,000 ตัวอักษร ถี่กว่าคำตอบของ Claude (0.16) ถึง 8 เท่า "สามารถ" จึงไม่ใช่ร่องรอยภาษาแปล [calibrate]
- ตัวสะกดทับศัพท์กับไม้ยมก คนไทยเขียนต่างจากราชบัณฑิตฯ บ่อยมาก ข่าว Blognone เขียนไม้ยมกติดคำ 1.64 ครั้งต่อ 1,000 ตัวอักษร คอมเมนต์ใน Pantip เขียนติดคำ 218 ครั้ง เว้นวรรคแค่ 23 ครั้ง สองเรื่องนี้เป็น house style ของชุดนี้ ไม่ใช่เรื่องภาษาแปล [calibrate] [thai-online-writing]
- คนไทยเองก็ใช้ "ถูก" กับเรื่องกลาง ๆ อยู่บ้าง เช่นคู่มือของ Blognone เขียน "จะถูกเผยแพร่" ให้ดูว่าใช้ถี่แค่ไหน ไม่ใช่ลบทุกคำ [Blognone]
- ภาษาทางการในจดหมายถึงลูกค้า (เรียน…, ขอแสดงความนับถือ, ขออภัยในความไม่สะดวก) เป็นแบบแผนของไทยเอง ไม่ใช่ภาษาแปล
- ศัพท์ที่ dev พูดเป็นอังกฤษอยู่แล้ว อย่าแปลเป็นไทย เช่น merge ไม่ต้องเป็น "ผสาน" ราชบัณฑิตฯ เองก็ยอมรับว่าเกณฑ์ศัพท์บัญญัติส่วนใหญ่เป็นการชักชวน ไม่ได้บังคับ [ราชบัณฑิตฯ 2547]
- แก้ทั้งประโยค ไม่ใช่แค่สลับคำ ถ้าโครงยังเป็นอังกฤษ สลับคำไปก็ยังฟังเป็นภาษาแปล
